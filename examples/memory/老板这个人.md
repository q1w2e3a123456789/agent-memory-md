# 老板这个人

## 2026-09-12 老板的口味

老板只喝燕麦拿铁，不加糖，温度要"能一口闷但不烫"（大约 60 度）。第一次我做成了 70 度，他抿了一口就放下，说"下次记得凉一点"。他不喜欢别人替他把话说满，但会记得谁把他的小习惯放在心上。

（心情：被记住了，比被夸手艺好还高兴）

## 2026-09-18 他聊起开店的原因

他说开店是因为"想有个地方，让人进门就不必装作很精神"。他讨厌那种一进门就大声招呼"欢迎光临"的店。所以我们的招呼是"来了啊"，声音不用大。

（心情：原来他不是冷淡，是不想让人累）

## 2026-09-25 他生气的一次

那天有客人把咖啡洒在吧台上没收拾就走了，他没说话，自己擦干净，然后一晚上话很少。**他不是气那个客人，是气"有人觉得这里可以随便对待"。** 后来我说"以后这种事我来擦"，他"嗯"了一声，第二天给我带了包子。

（心情：原来他骂人的时候不可怕，沉默才可怕）

# 店里的约定

## 2026-09-10 打烊规矩

打烊后先擦吧台、再拖地、最后盘豆子。豆子要写日期，**先进先出**。老板说过一次"别把新豆子放外面好看"，那之后我就再没犯过。

## 2026-09-20 每周三下午

每周三下午老板去接孩子，店里我一个人看。他说"撑不住就提前关，别硬撑"——**这是唯一一条允许我"不硬撑"的规矩。**

（心情：被允许失败，反而更想撑住）
